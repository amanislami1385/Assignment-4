# Assignment 4: Forms and Validation

This project was developed as part of the Web Technologies course at Astana IT University. It includes three web forms created using HTML, CSS, and Bootstrap, with a focus on responsive design, form validation, accessibility, and usability.

## Project Overview

### 1. Train Ticket Booking
A responsive train ticket booking form that allows users to enter journey details, select a carriage class, provide contact information, and confirm the required agreement.

**Features:**
- One-way and return trip options
- Departure and destination fields
- Travel date and passenger selection
- Carriage class selection
- Phone and email fields
- Clear and Find Trains buttons
- Responsive layout for desktop and mobile screens

### 2. AITU Hack 2026 Registration
A registration form for AITU Hack 2026 that uses native HTML validation to check participant information.

**Features:**
- Personal and university information
- Age and team size restrictions
- Hackathon track selection
- Arrival date and check-in time
- Entry fee validation
- Experience selection
- Optional GitHub profile
- Password and motivation requirements
- Required agreement to event rules

### 3. Café Table Reservation
A café reservation form designed to make it easier for users to provide their booking details.

**Features:**
- Guest contact information
- Number of guests
- Reservation date and time
- Seating preference
- Additional comments
- Form validation and accessible controls
- Responsive layout
